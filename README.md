# FAKO? - Faik Geçdoğan | Web GIS Personal Portfolio

A multi-page personal portfolio featuring a sleek dark theme, profile picture, contact info (faikgecdogan6@outlook.com), dynamic language switching (TR / EN), OpenLayers & Leaflet map integration, custom location markers, professional experience cards, and a radar-scanning earth GIF hero layout.

## How to Run
1. Unzip the file.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` via Live Server or directly in any web browser.
